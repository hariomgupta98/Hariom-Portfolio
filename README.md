# Hariom Portfolio

## Open on a laptop
1. Install Node.js and extract this ZIP.
2. Open this folder in VS Code and its terminal.
3. Run `npm install`, then `npm start`.
4. Open http://localhost:8080.

No MongoDB setup is needed: the project editor stores projects in data/projects.json.

## Open on your phone
1. Connect your phone and laptop to the same Wi-Fi.
2. Leave `npm start` running on the laptop.
3. Run `ipconfig` on Windows and find your Wi-Fi IPv4 address.
4. In your phone browser open `http://YOUR-LAPTOP-IP:8080` (example: http://192.168.1.5:8080).
5. If blocked, allow Node.js through Windows Firewall on private networks.

The phone cannot use localhost to reach your laptop. A public hosted URL is needed to view it away from your Wi-Fi. This ZIP is not a deployment.

## Easy editing
- Text and page sections: views/sections/*.ejs
- Full stack certificate: public/assets/certificates/full-stack-hariom-kumar.png
- Layout and mobile styling: public/css/responsive.css
- Images: public/assets/images/
- Admin login: http://localhost:8080/admin/login (run setup-admin first).

The certificate image was edited with the built-in image editor using this prompt: Replace only the recipient name Aditya Kumar with Hariom Kumar; preserve the remaining certificate design and wording.

The archive excludes installed dependencies, git history, and local environment secrets. Existing designs, projects, images, and other certificates are retained.

## Admin login and project CRUD
1. Run `npm run setup-admin` in the project folder.
2. Choose your admin username and a password of at least 12 characters. The setup saves a password hash in your local `.env` file.
3. Restart with `npm start` and open http://localhost:8080/admin/login.
4. After signing in, use **Manage projects** to view, add, edit, and delete projects. **Add project** appears only for a signed-in admin.
5. Sign out when finished. All create, update, and delete routes require authentication and a form token; hiding buttons alone is not the access control.

All existing featured projects are now included in the editor. Their artwork and supplementary links remain in their original card templates. The primary project link, name, and description can be changed in the editor.

Admin access also works on your phone using the laptop's Wi-Fi address. The earlier host-laptop-only restriction has been replaced by admin authentication. Do not commit `.env`. For HTTPS production hosting, set `NODE_ENV=production`, `ADMIN_USERNAME`, and `ADMIN_PASSWORD_HASH` in the host's environment settings. The hash value is generated by setup-admin. Sessions expire after four hours and on server restart. Store `data/projects.json` on persistent storage for hosting; this version is intended for one server process.

## Project images
On Add project or Edit project, choose an optional PNG, JPG, or WebP image (maximum 2 MB). A preview appears before saving. Edit lets you replace the image or select Remove current image. Saving text without selecting an image keeps the current image. Uploaded images appear in the admin dashboard and public portfolio; deleting the project removes its uploaded image. If a form validation error occurs, choose the image again before saving.

Images are stored in `public/uploads/projects/`; keep this directory alongside `data/projects.json` on persistent storage when hosting. No additional package or image service is required. A custom image on a featured project uses the standard image card; removing it restores the original featured artwork.

## Live project links
Add or edit a project and fill in Live project link below the image field. Use a full https:// URL. Saving displays a View live project button on the portfolio and admin card. The original Project or GitHub URL field remains separate. Leave the live link empty to hide its button.
